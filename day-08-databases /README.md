# Day 8 — Databases

The examples use a small shop database.

- [Relational modelling and SQL](1.%20Relational%20Modelling%20and%20SQL.md) — Tables, keys, constraints, an ER diagram, and SQL examples with results.
- [Normalisation, indexes and migrations](2.%20Normalisation%2C%20Indexes%20and%20Migrations.md) — First to third normal form, when to denormalise, when to add an index, and how to run a schema migration.
- [Transactions, concurrency and query performance](3.%20Transactions%2C%20Concurrency%20and%20Query%20Performance.md) — ACID, isolation, locks, MVCC, deadlocks, query plans, indexes, and N+1 queries.
- [Database connections and SQL vs NoSQL](4.%20Database%20Connections%20and%20SQL%20vs%20NoSQL.md) — Connection pooling, RDS Proxy, and when to use relational, document, key-value, and wide-column stores.
- [Replication, high availability and database scaling](5.%20Replication%2C%20High%20Availability%20and%20Database%20Scaling.md) — WAL and replicas, Multi-AZ and recovery, partitioning and sharding, Redis caching, and PostgreSQL maintenance.
- [PostgreSQL tutorial](6.%20PostgreSQL%20Tutorial.md) — A practice database with psql, table setup, queries, transactions, views, indexes, and backup and restore.
