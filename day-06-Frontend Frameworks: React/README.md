# Day 6 — React and Frontend Frameworks

- [React and frontend frameworks](1.%20React%20and%20Frontend%20Frameworks.md) — I cover components, props, JSX, state, and effects, then compare how a few frontend frameworks handle updates.
- [React Hooks in practice](2.%20React%20Hooks%20in%20Practice.md) — I show when I use state, effects, refs, memoisation, reducers, Context, and custom Hooks.
- [Reactivity, routing and debugging](3.%20Reactivity%2C%20Routing%20and%20Debugging.md) — I look at how the UI updates, where routing and data caching fit, and how I debug re-renders.
- [React internals, performance and migration](4.%20React%20Internals%2C%20Performance%20and%20Migration.md) — I cover Fiber, transitions, Suspense, and Server Components. I also explain how I would migrate an AngularJS app in steps and choose a framework.
